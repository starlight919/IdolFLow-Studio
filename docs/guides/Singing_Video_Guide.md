# 演唱 / 对口型视频指南

> 最后更新：2026-08-15

对口型任务使用 `lip_sync` 或 `dance_lip_sync` 模式。

## 必需输入

- 一张或多张 Anchor 图片（人物 + 场景）
- 一段口型参考视频
- 完整歌词文本

### 音频传入

对口型任务的参考音频有两种输入场景，靠「📹 视频 / 🎵 音频」标签页区分：

| 场景 | 操作 | 传视频 | 音频来源 |
|------|------|--------|---------|
| **视频 + 视频提取音频**（可选用不用） | 📹 视频 tab 选视频，勾选/取消「传参考音频」 | ✅ | 从视频提取 |
| **纯音频** | 🎵 音频 tab 选音频 | ❌ | 音频文件本身 |

- 有参考视频时，默认勾选「上传参考音频做口型同步」，系统会把**从视频提取**的音频上传给 Seedance 提升口型精度。可以取消（省一次上传），但最终 mux 阶段始终会用原始音频回灌到 `final.mp4`。
- **不提供"视频 + 独立音频"**：传视频时音频以视频提取为准；若在音频 tab 选过音频又切到视频 tab，会提示该音频被忽略（被视频提取音频覆盖）。
- **打时间戳不受「传参考音频」勾选影响**：勾选只控制「是否把音频上传给 Seedance 生成」；即使不勾，点「打时间戳」仍会从参考视频/音频**提取音频**用于播放定位、逐句打点。
- 若想「只传音频、不传视频」的纯口型模式，切到「🎵 音频」标签页选音频文件即可；该模式不涉及视频提取。

### 歌词时间戳（可选）

> ⚠️ **时间戳是可选的**：歌词照常在「歌词」框直接填写即可，**不打时间戳也能正常生成视频**。只有当你需要更精确的口型对齐时，才需要额外打时间戳。

歌词区域提供「打时间戳（可选）>」入口，可为每句歌词打时间戳，用于后续精确对口的滚动歌词生成。

**操作步骤**（仅在需要时间戳时）：
1. 先在「歌词」框逐行填写歌词（每行一句）
2. 上传参考音视频（音频直接用；视频自动分离音频，无需勾选「添加音频」）
3. 点「打时间戳（可选）>」打开编辑器
4. 播放歌曲，到每句歌词第一个字时点「添加时间点」（或按 Enter）
5. 点「保存」把时间戳写入任务

**编辑器交互**：

| 操作 | 行为 |
|------|------|
| 「添加时间点」/ Enter | 给当前句打点，自动跳下一句（只覆盖当前句，不影响其它句） |
| 点击某句 | 跳转定位到该句（不清空） |
| 某句右侧「↺」 | 重打这一句：清空该句时间点，从上一句开始播放、高亮定位到该句；第一句从音频开头播放 |
| ↑/↓ | 切换选中句 |
| 空格 | 播放/暂停 |

- 播放时自动定位到当前时间对应的已打点句子，并滚动到第二行位置
- 弹窗内播放器与「添加时间点」固定在顶部，歌词列表独立滚动

**键盘快捷键**：空格 = 播放/暂停，Enter = 打点，↑/↓ = 切换歌词行，Esc = 关闭。

**数据格式**：时间戳保存在任务的 `lyrics_timestamps` 字段：

```json
[
  { "text": "第一句歌词", "time": 1.234 },
  { "text": "第二句歌词", "time": 5.678 }
]
```

`time` 为播放秒数，未打点的句子为 `null`。时间戳会进入 prompt 生成（见 [Prompt_Design.md §12](Prompt_Design.md)）：

- 无有效时间戳（空或全 `null`）→ 普通歌词。
- 全部有时间 → 逐句输出 `1.21s开始唱"..."；`。
- 部分有时间 → 完整歌词 + 单独列出已标注时间点，其余自然衔接。

**时长对齐与时间戳偏移**：时间戳是在原始音频上打的。若参考视频用「前面补齐」（`pad_mode=front`），音频开头会补静音，歌词实际起唱时间整体后移，prompt 里的时间戳会自动加上 `ceil(总时长) - 总时长` 的偏移；「后面补齐」/「原始时长」无需偏移。详见 [Prompt_Design.md §2.4.1](Prompt_Design.md)。

## 任务配置

```json
{
  "mode": "lip_sync",
  "references": [
    {
      "name": "reference-1",
      "file": "singing.mp4",
      "duration": 15,
      "pass_reference_audio": true
    }
  ],
  "lyrics": "完整歌词文本..."
}
```

## 时长

- Seedance 2.5 上限 30s，非 2.5 上限 15s
- 视频时长自动向上取整（17.857s → 18s），视频末尾补帧、音频末尾补静音到整数秒
- 生成后 mux 阶段用原始音频回灌，ffmpeg `-shortest` 自然裁回原始长度
- 详见 [Video_Task_Workflow.md](Video_Task_Workflow.md) 时长处理章节

## Prompt 原则

参见 [Prompt_Design.md](Prompt_Design.md) 获取五层架构详情。核心原则：

1. 图片 1 负责人物身份、服装、场景、光线
2. 视频 1 负责口型时序（lip_sync）或同时负责动作（dance_lip_sync）
3. 参考音频负责发音、音节、节奏和起止停顿
4. 口型多源融合：歌词（linguistic）+ 音频（acoustic+temporal）+ 视频（visual+temporal）
5. 保持嘴形自然、转换流畅，限制过度张嘴、机械抖动和五官漂移

## 常见问题

| 问题 | 排查 |
|------|------|
| 口型不准 | 确认歌词完整、参考人脸清晰、`pass_reference_audio` 已开启 |
| 搬运字幕或场景 | 系统 prompt 已限制「只取口型」，可加 `constraints` 强化 |
| 动作太大 | 使用 `lip_sync` 模式（纯对口型，不模仿动作） |
| 口型延迟 | 确认参考音频与视频对齐，加 `constraints` 强调时间同步 |

> 提示：上表中的 `constraints`（任务附加约束）仅在自动模式下生效。若约束仍不够，可直接编辑「预览 Prompt」框——编辑后即视为「自定义 Prompt」，整段覆盖自动生成的歌词 / 时间戳 / 附加约束（需自行写清参考素材角色）。详见 [Prompt_Design.md §13.1](Prompt_Design.md)。
