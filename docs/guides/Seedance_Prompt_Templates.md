## 1. 外部最佳实践（提炼自官方指南与社区库）

### 1.1 一条完整 Prompt 的 8 个组成部分

来源：Seedance 2.5 提示词教程（CSDN，2026-08-10，CC 4.0 BY-SA）。
结构公式：

```text
主体 ＋ 场景 ＋ 具体动作 ＋ 景别 ＋ 运镜 ＋ 光线与风格 ＋ 声音 ＋ 一致性约束
```

| # | 组成部分 | 解决的问题 | 写法要点 |
| - | --- | --- | --- |
| 1 | 主体 | 画面里是谁 / 什么产品 | 具体到外貌、服装、身份 |
| 2 | 场景 | 时间、地点、环境 | 雨夜街道、霓虹都市、清晨森林 |
| 3 | 动作 | 主体具体做什么 | 写具体方向与速度，不写"高级感" |
| 4 | 景别 | 远 / 中 / 近 / 特写 | 决定信息密度 |
| 5 | 运镜 | 镜头如何移动 | 见 §1.3 词汇表 |
| 6 | 光线与风格 | 光源、色温、氛围 | 自然光 / 霓虹 / 柔光 / 电影感 |
| 7 | 声音 | 环境声 / 对白 / 音乐 | 与画面节奏匹配 |
| 8 | 一致性约束 | 哪些必须保持不变 | 脸型、发色、服装、不增人物 |

**示例（官方风格）**：

```text
雨夜街道远景，一名穿深灰色风衣的短发女生撑伞进入画面。
镜头从人物左侧缓慢跟拍，逐渐推进到面部近景。
暖色路灯在湿润地面形成倒影，雨声和脚步声清晰。
全程保持人物脸型、短发造型和风衣款式一致，不增加其他人物。
```

### 1.2 社区六维度结构（Seedance 2.0 Prompt Library）

来源：gracech0322-cmd/seedance-2-prompt-library（GitHub，2026-08-06，社区收集）。
维度可跳过，跳过则由模型自由生成：

| 维度 | 关键问题 | 标记法 |
| --- | --- | --- |
| Input | 用哪些素材？ | `@Image1` / `@Video1` 作为首帧 / 动作 / 运镜参考 |
| Content | 场景发生什么？ | 主角 + 地点 + 动作 |
| Style | 视觉 / 音乐风格？ | 吉卜力、暖调、电影感 |
| Camera | 如何拍摄？ | 中景、缓慢推近、平视 |
| Structure | 时间线 / 顺序？ | `0–3s …；3–10s …` |
| Edit | 修改什么？ | 把 `@Video1` 中猫换成狗 |

### 1.3 运镜词汇表（写具体动作，不写"高级感"）

来源：同上 CSDN 教程。一段镜头**最好只保留一个主运镜**，避免推进+环绕+升降同时出现导致模型顾此失彼。

| 运镜 | 作用 |
| --- | --- |
| 缓慢推进 | 从环境进入人物情绪 / 产品细节 |
| 缓慢拉远 | 交代空间关系，适合结尾 |
| 横向跟拍 | 跟随人物移动，速度感更明显 |
| 环绕拍摄 | 突出人物 / 产品主体 |
| 低机位仰拍 | 增加力量感 |
| 手持跟随 | 纪实、街头、临场画面 |
| 焦点转移 | 把注意力从前景引向后景 |
| 俯拍下降 | 先展示全局，再落到主体 |

### 1.3.1 灯光与镜头短语表（直接套用，提升"具体度"）

来源：Seedance《AI 视频提示词指南》（2026）。写 Prompt 时从下表挑词，避免"有电影感"这类空话。

**灯光**

| 效果 | 可直接用的短语 |
| --- | --- |
| 黄金时刻 | 黄金时刻光线、午后阳光、温暖定向阳光 |
| 戏剧性 | 戏剧性侧光、强烈阴影、明暗对比 |
| 影棚 | 干净影棚灯光、三点布光、产品灯光 |
| 忧郁 | 低调灯光、单烛光、黑色电影 |
| 自然户外 | 阴天漫射光、多云天、柔和环境光 |
| 夜晚/霓虹 | 霓虹灯反射、夜间城市灯光、赛博朋克灯光 |

**镜头距离 / 运动 / 角度**

| 类别 | 可直接用的短语 |
| --- | --- |
| 距离 | 特写、中景、广角定场镜头 |
| 推近 | 慢推轨前进、慢推入、柔和变焦推近 |
| 拉远 | 慢拉回、推轨拉远展现、变焦拉远 |
| 环绕 | 慢轨道环绕镜头、360 度旋转、环绕摄像机 |
| 侧向 | 慢向左摇、横向跟拍、摄像机向左滑动 |
| 垂直 | 慢向上倾斜、升降机上升、摄像机向上漂移 |
| 无运动 | 静态锁定摄像机、无镜头运动 |
| 手持 | 手持摄像机、轻微摄像机抖动、纪录片运动 |
| 航拍 | 航拍无人机视角、鸟瞰视角、俯视向下看 |

**风格/质量词**：电影级 4K、纪录片风格、商业摄影、黑色电影、自然纪录片、奢侈品产品摄影。

> 弱→强示例：`人走路` → `一位穿红大衣的女人自信地走在巴黎雨后湿滑的鹅卵石街道上，摄像机在视线高度跟拍，金色街灯倒影，电影级景深，慢动作`。

### 1.4 多镜头（30s 视频）时间拆分范式

```text
0—6s   远景交代场景，主体进入画面
6—14s  中景跟拍，推进主要动作
14—23s 特写 / 转场 / 节奏变化，形成高潮
23—30s 镜头拉远或稳定停留，给出明确结尾
```

> 核心叙事：`开场 — 动作推进 — 高潮 — 结尾`。结尾必须明确（停帧 / 拉远 / 稳定），否则易"结尾失控"。

### 1.5 人物一致性写法（图生视频 / 参考图生视频关键）

不能只写"保持人物一致"，至少固定：

- 人物外貌以参考图为准（如"参考图1为唯一标准"）；
- 全程保持相同脸型、五官比例、年龄、发色、服装；
- 动作幅度限制（如"只缓慢转头约30°，表情从平静变微笑"）；
- 明确否定项：不改变发色 / 服装 / 面部结构，不增加其他人物。

> 失败经验：人物变脸 → 减小转身幅度 / 减人数；镜头乱飞 → 只留一种主运镜；产品变形 → 加参考锁比例；结尾失控 → 明确停帧。

### 1.6 社区可复用风格模板（7 类常见风格）

来源：Seedance 2.0 Prompt Library（社区收集，仅作外部参考，不代表本项目分类）。每类均附"模板骨架"，可直接套用：

| 风格 | 模板骨架 |
| --- | --- |
| 电影感 | `Cinematic film style. {主角} in {地点}. Camera {运镜}. Lighting {灯光}. {动作}. Atmosphere: {雾/雨/戏剧光}. End with {史诗终镜}.` |
| 动漫动画 | 动漫风格 + 角色 + 地点 + 动作 + 能量特效 + 结束姿势 |
| AI 短剧 | 风格 + 角色 + 动作 + 对话 + 结尾（分镜 0–15s） |
| 商业广告 | 奢侈品风 + 产品 + 慢旋镜头 + 亮点 + 品牌结尾 |
| 社媒趋势 | 社媒风 + 正常情境 + 突发 + 反应 + 梗结尾 |
| 真实 Vlog/UGC | 手机视频风 + 人物 + 谈论 + 自然光 + 随意结尾 |
| 创意 VFX | 实验特效 + 粒子/光构成 + 变形 + 抽象结尾 |

### 1.7 社区多模态参考喂法（图 / 视频 / 音频分工）

综合 Seedance 2.5 R2V 指南、9 图 3 视频 3 音频实操、腾讯云音频参考解析等社区经验。
**核心思想：参考素材是「导演指令」而非「素材复制」——每份只负责一件事，并在 Prompt 里显式声明职责与优先级。**

#### 1.7.1 三类参考的职责边界

| 素材 | 负责什么 | 合适素材 | 不负责什么 |
| --- | --- | --- | --- |
| 参考图 | 身份（谁/产品外观）、场景、风格 | 干净角色/产品图、广角场景图、统一情绪板 | 不提供动作与运镜 |
| 参考视频 | 动作（身体/物体路径）、运镜（构图/镜头路径） | 简短干净动作视频、白模预演、运镜动画（2–15s MP4/MOV） | 不提供画面内容（只借运动/运镜） |
| 参考音频 | 音频（音乐/台词/音效）与节奏 | 节奏清楚的干净音轨（MP3/WAV） | 不提供画面 |

> 口诀：**图管"长什么样"，视频管"怎么动"，音频管"什么节奏/情绪"。**

#### 1.7.2 @引用编号与显式分工（最关键）

社区一致强调：**用 `@image1` / `@video1` / `@audio1` 在 Prompt 中显式分配每份参考的职责，不要写"用这些素材做个好视频"**。
示例（产品广告）：

```text
用 @image1 控制产品形状和标签位置，把产品放进 @image2 的台面环境。
参考 @video1 的慢速环绕和最后正面停住。
产品结构优先级高于动作视频里出现的任何物体形状。
```

本项目 custom 模式的做法：系统自动按类型编号（参考图1 / 视频1 / 音频1），用户在 chips 旁下拉选「角色标签」（动作参考 / 运镜参考 / 节奏驱动 …），由 `_fuseCustomRefs` 融合进 Prompt。

#### 1.7.3 优先级裁决句（避免"视频元素渗漏 / 细节被抹平"的核心）

社区多篇翻车案例的共同根因：**参考视频的画面元素被模型渗进成品（如手部动作、桌面摆件乱入），或视频干扰把产品细节抹平**。修复方式都是同一句裁决：

```text
产品外观以图片参考为准，视频仅参考镜头运动与节奏，音频仅参考情绪与卡点。
```

**本项目已内置该逻辑**：当用户同时提供参考图与参考视频/音频时，`_fuseCustomRefs` 会自动追加裁决句（见 §3 后端 `_fuseCustomRefs`）。手动写 R2V 模板时也应保留这类裁决句（参考 §2「多参考组合」模板）。

#### 1.7.4 数量上限与喂法建议

| 入口 | 参考图 | 参考视频 | 参考音频 |
| --- | --- | --- | --- |
| 社区实测（Seedance 2.0/2.5） | 最多 9 张 | 最多 3 段 | 最多 3 段 |
| 建议起步 | 2–4 份 | 1 段（越短越纯，4s 典型） | 1 段（已授权 BGM） |

喂法顺序（带货视频实战）：先备图（多角度锁外观）→ 再备节奏视频（剪最典型几秒）→ 再备音频（调性对版即可）→ 提示词只写「优先级裁决句」。

#### 1.7.5 参考音频与口型 / 节奏（来自腾讯云解析）

Seedance 为原生音视频联合生成：参考音频可作输入条件之一，用于**驱动背景音乐、环境音效或角色配音**，并与画面节奏精确对齐。

- **节奏驱动**：参考音频（音乐/脚步声）约束动作节奏，缓解"嘴型对不上台词、脚步差半拍"痛点。
- **口型/配音**：单说话人/配音场景，参考音频可辅助生成对口型的中配音（多说话人唇音同步仍不精确，这是模型已知局限）。
- 注意：本项目 custom 的参考音频默认 `pass_reference_audio:true`（克隆/对齐音频），若仅想要"节奏感"而非"替换音轨"，可在补充备注里写"仅参考节奏，不替换原音频"。

#### 1.7.6 翻车规避清单（交付前自检）

- [ ] 参考图之间身份/服装一致（避免两张脸冲突）。
- [ ] 参考视频剪短、干净（绿幕佳），避免无关元素渗漏。
- [ ] Prompt 含优先级裁决句（图优先于视频的外观）。
- [ ] 细节易丢则加特写图（如产品螺纹特写到 3 张）。
- [ ] 音频分拆（音乐/台词/音效分开），不喂混合长音轨。
- [ ] 素材来源干净（自有/授权），商用勿直投竞品视频。

#### 1.7.7 参考图作用域设计（为什么参考图也要选"作用"）

**背景**：早期 custom 模式只给参考视频/音频提供「角色下拉」，参考图被**硬编码为「身份/风格」**。但一张图能表达的远不止身份——它可能是服装、场景、构图、Logo、整体风格。若不显式标注，模型会把所有图都当成"身份/风格"处理，导致：多张图身份冲突（两张脸互相干扰）、或本该锁定的服装/场景被模型自由发挥。

**设计决策**：参考图与视频/音频**统一采用「作用域下拉」**，预设 6 类（依据 §1.7.1 的职责边界 + 实战高频诉求）：

| 预设 | 语义 | 典型场景 |
| --- | --- | --- |
| 身份参考 | 锁定"谁/产品外观"（脸型、发色、体型、主体造型） | 人物出镜、产品主体 |
| 服装参考 | 锁定"穿什么"（款式、配色、材质） | 时尚走秀、虚拟人换装 |
| 场景参考 | 锁定"在哪"（环境、布景、空间关系） | 把主体放进特定场景 |
| 风格参考 | 锁定"整体调性"（画风、影调、质感） | 艺术短片、统一视觉 |
| 构图参考 | 锁定"怎么排"（景别、机位、元素位置） | 产品摆位、海报感 |
| Logo参考 | 锁定"品牌标记"（水印级元素位置/形状） | 商业广告角标 |

随时可选「自定义…」自由补语义（如"配饰风格""背景纹理"），填错点「返回」回预设。

**设计理由（来自社区实践）**：
- **多图必须显式分工**：§1.7.2 已强调 `@image1/@image2` 要分别声明职责。Seedance 不会自动裁决"两张图谁负责什么"，不分配就会按"都像"处理→ 身份冲突。**显式作用域 = 把分工写进 Prompt 让模型按分配执行**。
- **图与视频按域隔离**：图负责"静态外观/元素"，视频负责"运动/运镜"（§1.7.1 口诀）。给图单独选"服装/场景/风格"而非笼统的"身份/风格"，正是把"外观"这一域进一步切片，使参考图内部也互不打架。
- **默认兜底**：用户不填作用时，系统仍按"身份/风格"处理（向后兼容旧行为），保证"不填也能生成"。

#### 1.7.8 参考说明为何要放在 Prompt 前部（而非末尾）

**背景**：初版 `_fuseCustomRefs` 把「参考说明：…」**追加到 Prompt 末尾**。但社区（heymarmot Seedance 2.0 指南、R2V 实战）反复验证：**把参考分工 / 优先级裁决作为"高级指令"放在 Prompt 最前部，比追加在末尾更能稳定约束生成**。

**设计决策**：本项目改为——`参考说明：…` 统一置于 `custom_prompt` **最前面**（首行），生成主体描述紧随其后：

```text
参考说明：参考图1（身份参考）：cyber-cat.png；视频1（动作参考）：motion.mp4。
外观与身份以参考图为准；视频仅参考其运镜/动作，不复制其画面元素；音频仅参考节奏/氛围。
一只机械赛博猫，蓝色发光电路纹路，在城市霓虹雨夜的屋顶缓步行走。镜头运动：0-3s 推近，3-8s 环绕。电影感，雨丝反光，冷色调。
```

**设计理由**：
1. **优先级信号前置**：Seedance 对 Prompt 开头权重更高，把"外观以图为准 / 视频只借运镜"放在最前，等于先定规矩再生成，降低"视频元素渗漏 / 细节被抹平"（§1.7.3 的根因）。
2. **与 §1.7.2 的 `@引用` 范式一致**：社区惯例就是在正文前先声明各参考职责，而非文末补注。
3. **降低随机性**：参考分工是"约束条件"而非"描述内容"，约束前置可减少模型自由发挥的空间。

> 注意：这是 custom 模式专属处理；后端自动生成模式（lip_sync/motion 等）走七层架构，参考职责在 Layer 2 以 `@image1 / @video1 / @audio1` 显式声明（见 §3），不套用此"前置"规则——两者范式不同但理念一致（职责单一、显式声明边界）。

## 4. 模板编写通用规范

综合 §1 外部实践与项目现状，约定如下：

1. **先讲任务，再讲限制**：开头直接定义"要完成什么"，避免一上来连续"严禁/不得"。
2. **正向描述优先**：用"保持人物身份稳定"而非罗列"不得换人/不得脸变"。
3. **一段一个主运镜**：单段镜头只保留一种运镜（推进 / 环绕 / 跟拍之一）。
4. **分时段给结尾**：超过单镜头时按 `0-Xs …；Xs后 …` 拆分，结尾必须明确（停帧 / 拉远）。
5. **参考职责单一**：图片管身份、视频管动作 / 运镜、音频管节奏 / 音色；冲突时以本 Prompt 描述优先。
6. **占位符统一用 `【】`**（前端 custom 模板），后端自动模板用 `{变量}` 由代码填充。
7. **一致性约束必写**：图生 / 参考生视频必须固定脸型、发色、服装、否定项。

### 4.1 好 / 坏对比

| 维度 | 坏（模型易失控） | 好（具体、可执行） |
| --- | --- | --- |
| 动作 | "人物做一个高级感的动作" | "人物从画面右侧走向左侧，步伐平稳，3 秒走完" |
| 运镜 | "镜头很有电影感地运动" | "0-3s 缓慢推近面部，3s 后环绕主体" |
| 一致性 | "保持人物一致" | "以参考图1为唯一标准，脸型/发色/服装全程不变，不增加其他人物" |
| 参考 | "参考这个视频" | "视频1仅负责动作幅度与节奏，物体形状以本 Prompt 为准" |
| 结尾 | （无结尾描述） | "8s 后镜头拉远定格，主体居中" |

### 4.2 占位符填写规则（前端 `【】` 模板）

- 每个 `【】` 都要替换，不要保留空占位符或 `【此处填写】` 字样提交生成。
- 占位符内写**具体值**，如 `【深灰色风衣短发女生】` 而非 `【人物】`。
- 时间分镜用 `0-Xs` / `Xs后` 表述，单位统一为"秒"。
- 多参考时显式分工：`参考图用于【身份】；参考视频用于【动作】`，避免"都参考"。
- 不确定时用模板推荐值（如 `光线【自然光/霓虹/柔光】` 三选一）。

| 火山引擎 R2V 官方指南 + 腾讯云音频解析 | 图管外观 / 视频管动作运镜 / 音频管节奏的按域分工 |
| Seedance 2.0 Prompting Guide（显式 `@引用`） | Layer 2 用 `@image1 / @video1 / @audio1` 而非"图片1负责…"的工程语言 |
| Seedance《AI 视频提示词指南》（正向优先） | "负责"类措辞改为正向可执行约束（"锁定…/仅提供…/"） |
| 上述"单一职责 + 显式声明"原则（直接推论） | 纯音频模式不列出视频行，Layer 1 任务句同步改写，不向模型描述不存在的素材 |

## 7. 端到端示例（custom 模式）

以"用参考图生成一位女生在雨夜街道撑伞行走的短片"为例，串起从模板到生成的全过程。

1. **选模板**：在 custom 面板 Prompt 框右侧下拉选择「人物 / 人物肖像」。
2. **填占位符**：模板 `一位【外貌特征】的【人物】，【动作描述】，身处【场景】。镜头运动：0-3s【推近面部】，3-7s【环绕】，电影质感，细节精致，光线【柔光/侧光】。` 填为：
   ```text
   一位穿米色风衣的短发女生，撑伞在雨夜街道缓慢行走，身处霓虹都市。
   镜头运动：0-3s 推近面部，3-7s 环绕，电影质感，细节精致，光线 柔光。
   ```
3. **加参考图**：点「添加素材」从任务文件夹选一张人物图；若没有，点「现场生成」→「打开 Anchor 生成器」用 GPT Image 2 生成候选，审核后「用作参考图」回填。
4. **（可选）加参考视频/音频**：点「参考视频 / 音频」下的「添加素材」，系统自动编号视频1/音频1，给每个选一个作用标签（如"动作参考"）。
5. **生成**：保存并启动，后端 `_submit_custom` 把 Prompt + 各参考按职责传入 Seedance。

> 该流程全程在 custom 分支内完成，不影响 anchor / lip_sync / motion 等其它任务。

| 术语 | 含义 |
| --- | --- |
| Seedance | 火山引擎视频生成模型（即梦 / 豆包 Pro 底层），本项目视频生成引擎 |

## 9. 常见问题与避坑

**Q1：人物生成后"变脸"怎么办？**
A：减小动作幅度（如只转头 30°）、减少画面人数；并在一致性约束固定脸型/发色/服装，参考图作为唯一标准。

**Q2：镜头"乱飞"怎么办？**
A：一段只保留一种主运镜（推进 / 环绕 / 跟拍之一），不要叠加。

**Q3：产品 / 物体变形怎么办？**
A：加参考图锁比例与外观，并写明"物体形状以本 Prompt 为准，不被参考视频里的物体干扰"。

**Q4：视频结尾失控？**
A：明确结尾（停帧 / 拉远 / 稳定停留），按 `0-Xs …；Xs后 …` 拆分。

**Q5：多参考素材互相打架？**
A：遵循 Reference Ownership，给每份参考单一职责（图管身份、视频管动作/运镜、音频管节奏/音色），冲突时以本 Prompt 描述优先。

**Q6：custom 模板改完不生效？**
A：前端模板以 `task.js` 的 `CUSTOM_PROMPT_TEMPLATES` 为事实来源，改完需同步本文档 §2；确认 `name` 唯一、占位符用 `【】`。

**Q7：后端自动生成的 Prompt 在哪里看完整版？**
A：完整七层范本在 `Prompt_Design.md` §17；本文档 §3 仅为索引 + 可读片段，勿在此手改。
