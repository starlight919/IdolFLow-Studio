操作指南
🎬 视频任务（主工作台）
  • 生成方向：对口型 / 口型+动作 / 模仿动作 三种模式，决定素材怎么传给 Seedance。
  • 对口型三种驱动：
    • 🎵 音频 tab = 纯音频驱动（只传音频对口型）
    • 📹 视频 tab + 勾"传参考音频" = 音视频驱动（画面+提取音频）
    • 📹 视频 tab + 不勾 = 视频驱动（只从视频学口型）
  • 时长对齐：原始时长（不补齐）/ 后面补齐 / 前面补齐。最终都会裁回原始时长。
  • 歌词：对口型 / 口型+动作任务逐行填写歌词即可，系统据此对齐口型。时间戳为可选——如需更精确的口型对齐，点「打时间戳（可选）>」逐句打点；不打时间戳也能正常生成。
  • 候选数：每个 Anchor 生成的候选视频数，审核时可挑选。
  • 口型+动作 / 模仿动作必须传视频；对口型模式才可选纯音频。
  • 任务文件夹：先确定任务文件夹再上传/选择素材；未确定时上传会禁用，缺素材时提示可点击「去现场生成 / 去上传」直接跳转。
  • 切换任务文件夹：会清空已选的 Anchor、音视频、歌词和附加约束，切换前会弹窗确认。
  • 选择 Anchor 图片：默认进入 `anchors/` 根目录（上传与「设为 Anchor」的图都在这），列表会显示缩略图预览；若存在现场生成的候选（`generated/`），会提示引导进入。
  • 缺失素材：编辑任务时若引用的图片/音视频已不存在，素材区会标红提示「文件已不存在」，需移除或重新选择后才能保存/生成。
  • 取消 / 新任务：编辑已保存任务时，顶部按钮会变成「取消」，点击放弃修改并清空表单；新建状态下显示「新任务」，点击清空重来。取消后需重新选择任务文件夹。
  • 保存方式：编辑并改了任务名或文件夹后点保存，会询问「保存为新任务」还是「更新原任务」——前者保留旧任务新建一份，后者覆盖旧任务。
🎨 Anchor 生成器
  • 选择数据目录 + 参考图，为每个参考点绑定来源图，可生成人物/场景素材。
  • 每张参考图下方可填写补充描述（可选），输入实时保存，切换/新增图片不会丢失。
  • 画质/风格、禁止项标签点选后实时合并到描述框，可与手写描述叠加，反复编辑不重复。
  • 生成的图片存入该目录 anchors/ 根目录，供同目录视频任务使用。
  • 审核时可将候选「设为 Anchor」（复制到 anchors/ 根目录），也可「取消 Anchor」撤销；被视频任务引用的图不会被误删。
  • 取消 / 新任务：编辑已保存的 Anchor 任务时，顶部按钮会变成「取消」，点击放弃修改并清空；「数据目录」也支持切换，切换会清空已选参考图（弹窗确认）。
  • 视频任务里的「现场生成」先展示说明（GPT Image 2），再点「打开 Anchor 生成器」跳转。
  • 特殊需求可自由文本描述，系统自动解析。
📊 运行 & 审核
  • 运行：展示所有视频/Anchor 任务的生成进度，可刷新。
  • 审核：查看已生成候选视频，用播放器控制栏或右键保存到本地，自动选中最近任务。
  • 恢复轮询：服务重启后已提交的候选会自动恢复继续生成；若运行中断，可点运行记录上的「恢复」凭已提交任务继续轮询，无需重新提交。
其他
  • 保存任务后可重复运行；同一文件夹可建多个不同任务。
  • 删除任务时可选择是否同时删除本地生成文件。
  • Asset 清单：展示已上传到 Seedance 的素材缓存，通过文件指纹自动复用（源文件未变则跳过上传）；仅在需要强制重新上传某素材时才点 🗑 删除对应缓存。
  • 按钮旁 ? 图标悬浮可查看该项说明。
